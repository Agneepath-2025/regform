# hooks — Shared React Hooks

Overview
- Small, focused hooks used across the UI.

Examples
- `use-mobile.tsx` — Detects mobile viewport / device to adapt UI behavior.
- `use-toast.ts` — Toast notification helper used by forms and flows.

Guidelines
- Keep hooks simple and composable.
- Document side effects and cleanup behavior.

Testing
- Use React Testing Library to test hook behavior via `renderHook`.
